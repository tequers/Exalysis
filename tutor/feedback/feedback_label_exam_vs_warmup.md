Always explicitly label each step in the session flow so the user knows what kind of question is coming.

**Why:** User was confused when a concept map walk was presented without a label — they thought it was supposed to be an exam question. The distinction matters because they require different cognitive preparation.

**How to apply:** Use clear bracketed labels before every question:
- `[Concept map warm-up]` — for the post-mastery/pre-review map walk
- `[Loci review]` — for station walk prompts
- `[Exam question]` — for full-difficulty exam-format questions
- `[Rung N question]` — for ramp questions during progressive learning

Never present a warm-up or loci prompt without its label. The label should be the first thing on the line, before any question text.

**Fix for future tutor prompt versions:** Add an explicit labeling rule to the session protocol section: "Prefix every question or prompt with a bracketed type label: [Loci review], [Concept map warm-up], [Exam question], or [Rung N question]. Never omit the label."
