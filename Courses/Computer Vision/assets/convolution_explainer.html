Key concepts
Weight sharing The kernel weights are identical at every position. One 3×3 kernel = 9 learned parameters, regardless of image size.
Local receptive field Each output cell sees only its 3×3 neighbourhood — not the whole image.
Feature map The full output grid. Each value = "how much does this kernel's pattern appear here?"
Output size Without padding: (W − k + 1) × (H − k + 1). 6×6 input, 3×3 kernel → 4×4 output.
